# Свидетели: входы, на которых код не даёт ни одной верной цифры

«Доказанная граница стала туже в 8145 раз» — утверждение верное и неубедительное.
Человек слышит в нём оценку сверху, то есть разговор о том, чего может не быть.
Убеждает другое: вот эти числа, подайте их в свою функцию, вот её ответ, вот
правильный. Это проверяется за минуту и не требует верить ни одному нашему слову.

Ниже — найденные такие входы. Ответы получены исполнением формы ровно так, как её
исполнит машина, и сверены с эталоном на Decimal.

Счёт по классам веду раздельно и нарочно. Случай, где написанная форма не даёт НИ
ОДНОЙ верной цифры, — это дефект: ответа просто нет. Случай, где обе формы дают
числа и предложенная чуть ближе, дефектом не является; на `cpvdot` это 15.8 цифры
против 17.7, то есть разница в одну младшую единицу. Ставить их в один список
значило бы считать находки нечестно.

| библиотека | диапазон проверки | ответа нет вовсе | просто точнее |
|---|---|---:|---:|
| raylib (`float`) | ±1e20 | **7** | 1 |
| box2d (`float`) | ±1e20 | **2** | 1 |
| Chipmunk2D (`double`) | ±1e200 | **2** | 0 |

Диапазон у Chipmunk другой не случайно: он считает в `double`, и квадрат
промежуточной величины там переполняется не на 1e20, а около 1e154. Болезнь та же,
порог другой.

Повторить:

```
python tools/witness.py raylib --range=-1e20..1e20
python tools/witness.py Chipmunk2D --range=-1e200..1e200
```
